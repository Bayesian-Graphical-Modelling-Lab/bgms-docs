Fitting a model

The main entry point is bgm(). It accepts a data frame or matrix of mixed binary, ordinal, and continuous variables and estimates a Markov Random Field.

The Wenchuan dataset is included in the package, and contains ordinal measures of symptoms of posttraumatic stress from 362 survivors of the 2008 Wenchuan earthquake.

library(bgms)

data(Wenchuan)

fit = bgm(Wenchuan, seed = 1234)

By default, bgm() runs four parallel MCMC chains using the No-U-Turn Sampler (NUTS), in combination with Bayesian edge selection. Here we use seed = 1234 for reproducibility.

coef() returns posterior mean matrices: $pairwise contains the interaction strengths and $indicator contains edge inclusion probabilities.

Network plot

To visualize the estimated network, we select the edges with posterior inclusion probabilities 0.5 or up, and plot the result using the qgraph package.

library(qgraph)

median_probability_network = coef(fit)$pairwise
median_probability_network[coef(fit)$indicator < 0.5] = 0.0

qgraph(median_probability_network,
  theme = "TeamFortress",
  maximum = 1,
  fade = FALSE,
  color = c("#f0ae0e"), vsize = 10, repulsion = .9,
  label.cex = 1, label.scale = "FALSE",
  labels = colnames(Wenchuan)
)

In this plot, edges with posterior inclusion probability below 0.5 are set to zero, so only edges with minimum evidence for inclusion appear in the plot.

Continuous data

For continuous variables, bgms fits a Gaussian graphical model. The interface is identical; only the variable_type argument changes.

As a continuous-data example, we use the classic examination marks dataset from Mardia, Kent, and Bibby (1979), available in the ggm package.

library(ggm)
data(marks)
head(marks)
fit_ggm = bgm(marks, variable_type = "continuous", seed = 1234)
summary(fit_ggm)

The pairwise effects are partial correlations (off-diagonal entries of the standardized precision matrix). Missing values can be imputed during sampling with na_action = "impute".
